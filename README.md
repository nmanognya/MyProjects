## Portfolio Principles

These projects are intentionally scoped as maintainable reference implementations rather than claims of operating real customer production systems. Each project emphasizes engineering decisions that matter in production environments: infrastructure as code, automation, security, reliability, observability, testing, rollback, scalability, and cost awareness.

No credentials, customer data, proprietary code, or fabricated production metrics are included.
